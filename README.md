# Curso Qapitão Python

Este projeto contém os exercícios e mini-projetos desenvolvidos durante o curso de Python, focado em QA Engineers. O material cobre desde os conceitos mais básicos até programação orientada a objetos, passando por estruturas de dados e controle de fluxo.

## Tecnologias Utilizadas

- **Python**: Linguagem de programação utilizada em todos os exercícios e projetos

## Estrutura do Projeto

O projeto está organizado em arquivos que seguem uma progressão de dificuldade, começando com conceitos básicos e avançando para tópicos mais complexos.

### Arquivos Básicos

- **hello.py**: Primeiro programa demonstrando o uso básico da função `print()`
- **variaveis.py**: Introdução a variáveis e formatação de strings com f-strings
- **operadore.py**: Demonstração de operadores aritméticos, de comparação e lógicos
- **inputs.py**: Recebimento de entrada de dados do usuário com `input()`
- **idade.py**: Estruturas condicionais básicas (if/else) e conversão de tipos
- **contador.py**: Loop `while` para repetição de código
- **listas.py**: Trabalho com listas e loops `for` para percorrer elementos
- **dic.py**: Uso de dicionários para armazenar dados em pares chave-valor
- **funcoes.py**: Criação de funções, uso de parâmetros e valores de retorno
- **range.py**: Função `range()` para gerar sequências numéricas em loops
- **menu.py**: Menu interativo usando loop infinito com `while True` e `break`
- **banco.py**: Programação Orientada a Objetos (POO) com classes, herança e métodos

### Mini-Projetos

- **mini-projeto-1.py**: Sistema de cadastro básico coletando dados do usuário
- **mini-projeto-2.py**: Sistema de controle de entrada baseado em idade usando múltiplas condições
- **mini-projeto-3.py**: Sistema de lista de convidados e geração de tabuada usando listas e loops
- **mini-projeto-4.py**: Sistema de autenticação com validação de senha usando loop `while`
- **mini-projeto-5.py**: Sistema de cadastro aprimorado utilizando dicionários para organizar dados
- **mini-projeto-6.py**: Sistema de cálculo de frete demonstrando funções com cálculos e retorno de valores

## Resumo do Conteúdo Aprendido

### Conceitos Básicos

O curso inicia com os fundamentos da programação em Python. Aprendemos a exibir mensagens na tela, trabalhar com variáveis de diferentes tipos (texto, números) e formatar strings usando f-strings para criar mensagens mais legíveis.

### Operadores

Foram abordados os diferentes tipos de operadores disponíveis em Python: aritméticos para realizar cálculos matemáticos, de comparação para verificar relações entre valores, e lógicos para combinar condições booleanas.

### Interação com o Usuário

Aprendemos a receber informações do usuário através da função `input()`, que permite que o programa espere por dados digitados antes de continuar a execução. Também vimos a importância de converter os dados recebidos para o tipo correto (como converter texto para número).

### Controle de Fluxo

Um dos temas mais importantes foi o controle de fluxo do programa. Através de estruturas condicionais (`if`, `elif`, `else`), aprendemos a fazer o programa tomar decisões baseadas em condições. Os loops (`while` e `for`) permitem repetir blocos de código, seja até uma condição ser satisfeita ou para percorrer coleções de dados.

### Estruturas de Dados

Foram apresentadas duas estruturas fundamentais: listas, que armazenam coleções ordenadas de itens, e dicionários, que armazenam dados em pares chave-valor. Ambas são essenciais para organizar e manipular informações em programas mais complexos.

### Funções

Aprendemos a criar funções para organizar o código em blocos reutilizáveis. Funções podem receber parâmetros, realizar processamentos e retornar valores, tornando o código mais modular e fácil de manter.

### Programação Orientada a Objetos

O conceito mais avançado abordado foi a Programação Orientada a Objetos (POO). Através de classes, aprendemos a criar modelos que representam entidades do mundo real. A herança permite que classes compartilhem características comuns, enquanto cada classe pode ter comportamentos específicos através de métodos próprios.

### Aplicação Prática

Os mini-projetos consolidam todo o conhecimento adquirido, demonstrando como combinar os conceitos aprendidos para criar programas funcionais. Desde sistemas simples de cadastro até cálculos mais complexos, cada projeto exercita diferentes habilidades e mostra a aplicação prática dos conceitos estudados.

## Como Utilizar

Cada arquivo pode ser executado independentemente usando Python. Para executar um arquivo, use o comando:

```
python nome_do_arquivo.py
```

Todos os arquivos contêm comentários em português explicando o funcionamento do código, facilitando o entendimento e a manutenção.
